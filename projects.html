AIDEAS-OEIS — AI-Driven Evaluation of Arithmetic Sequences in OEIS

A hybrid verifier that reads OEIS entries and flags formulas that don't hold. Qwen2.5-Math:7b runs locally through Ollama, and SymPy and LODA program synthesis check what it produces.

  • Three verifiers: LODA (≈19% hit rate) → LLM writes the formula as code, run in a restricted Python sandbox → SymPy closed-form evaluation; a Bayesian classifier combines them into one confidence score.
  • 2,041 sequences: 51.6% high-confidence valid, 40.3% need human review, 8.1% LLM interpretation errors — stable under Wilson 95% intervals.
  • Survives crashes and resumes (SQLite state per sequence), runs in Docker, exports CSV/JSON/SQLite.
